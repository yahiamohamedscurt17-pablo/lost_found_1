# WE Lost & Found — مشروع المفقودات والمعثورات

موقع PHP + MySQL تعليمي لإدارة بلاغات الأشياء المفقودة والتي تم العثور عليها، مع اختيار فصل الطالب من A1 إلى C6، وتحديد نوع الحساب (طالب أو إدارة المدرسة).

## المتطلبات
- XAMPP (Apache وMySQL)
- PHP 8.0 أو أحدث، مع PDO MySQL وFileinfo
- MySQL / MariaDB

## التثبيت
1. فك الضغط داخل `C:\xampp\htdocs\lfedit`.
2. افتح XAMPP وشغّل Apache وMySQL.
3. افتح `http://localhost/phpmyadmin`.
4. من تبويب Import، اختر `database.sql` ونفّذه. الملف ينشئ قاعدة البيانات `lost111` والجداول تلقائيًا.
5. افتح `config.php` وتأكد من بيانات MySQL. إعداد XAMPP الافتراضي غالبًا:
   - host: `localhost`
   - database: `lost111`
   - username: `root`
   - password: فارغة
6. افتح `http://localhost/lfedit/`.

## إنشاء حساب إدارة المدرسة
- من صفحة إنشاء الحساب اختر «إدارة المدرسة» وأدخل رمز الإدارة.
- الرمز الافتراضي للمشروع التجريبي موجود في `config.php` باسم `ADMIN_REGISTRATION_CODE` وقيمته `LOST111-ADMIN-2026`. غيّره إلى رمز خاص بالمدرسة قبل مشاركة الموقع مع الآخرين.
- حساب الطالب يحتاج إلى اختيار الفصل، أما حساب الإدارة فلا يحتاج إلى فصل.
- بعد تسجيل الدخول، الطالب ينتقل إلى صفحة إضافة البلاغات، والإدارة تنتقل إلى لوحة الإدارة.

## الصفحات
- `index.php` الصفحة الرئيسية.
- `register.php` إنشاء حساب، مع اختيار الفصل من A1 إلى C6.
- `login.php` تسجيل الدخول.
- `browse.php` تصفح البلاغات والبحث والتصفية حسب الفصل والنوع.
- `create_report.php` إضافة بلاغ مفقود أو معثور عليه.
- `report.php` تفاصيل البلاغ والرسائل وتحديث الحالة.
- `my_reports.php` بلاغات الطالب.
- `admin.php` إدارة البلاغات والمستخدمين.
- `config.php` الاتصال بقاعدة البيانات والدوال المشتركة.
